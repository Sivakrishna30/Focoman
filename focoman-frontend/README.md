# Focoman Frontend

Next.js frontend for the Focoman photography studio business operating system.

## Architecture

The frontend is organized using a feature-based structure. Shared UI components, services, hooks, utilities, and types live under `src/`, while business modules live under `src/features/`.

## Feature Modules

- `dashboard`
- `orders`
- `customers`
- `employees`
- `payments`
- `leads`
- `partner-services`
- `auth`
- `customer-portal`
- `notifications`
- `integrations`

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
