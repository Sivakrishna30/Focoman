# Focoman Tanglish Style Guide & Terminology Standard

**Status:** ACTIVE STANDARD  
**Domain:** Spoken-Tamil in English script for Photography Studio BOS  

---

## 1. Guiding Principle

Tanglish in Focoman represents the **natural, professional spoken language** used by modern Tamil-speaking photography studio owners, cinematographers, and editors in day-to-day business and WhatsApp communications.

- **DO:** Write natural spoken Tamil with consistent English phonetic spelling.
- **DO:** Keep standard business, studio, and photography terms in English (e.g., *RAW, Album, Shoot, Order, Payment, Crew, Deliverables*).
- **DO NOT:** Create clumsy mechanical transliterations of English UI buttons (e.g., avoid "Sign In pannunga" for a simple "Sign In" button).
- **DO NOT:** Randomly mix Tamil script within an English-script Tanglish sentence.

---

## 2. Standard Word List & Transliteration Policy

| Concept | Preferred Tanglish Spelling | Forbidden / Inconsistent Alternatives | Context Example |
| :--- | :--- | :--- | :--- |
| Do (Imperative/Polite) | `pannunga` | `panunga`, `pannuga`, `seyyavum` | *Details check pannunga.* |
| Can do / Let's do | `pannalaam` | `pannalam`, `panalam` | *Next step start pannalaam.* |
| Completed / Finished | `mudinjadhu` | `mudinchathu`, `mudinjithu`, `aachu` | *Event shoot mudinjadhu.* |
| Is pending | `pending-la irukku` | `pending irukku`, `pending-ah iruku` | *Balance payment pending-la irukku.* |
| Is ready | `ready-aa irukku` | `ready ah iruku`, `ready irukku` | *RAW photos ready-aa irukku.* |
| Verify / Check | `check pannunga` | `check seyyavum`, `parunga` | *Crew schedule check pannunga.* |
| Save / Update | `save pannunga` / `update pannunga` | `save seyyavum`, `save panunga` | *Changes save pannunga.* |
| In one place | `ore idathula` | `ore edathula`, `ore idathil` | *Ellame ore idathula manage pannunga.* |
| From / To | `mudhal ... varai` | `irundhu ... varaikkum` | *Booking mudhal delivery varai.* |

## 3. UI Control & Single-Word Button Rule

For basic UI controls, action buttons, table column headers, and status tags, use standard English words across all modes:

| UI Control | Tanglish Label | Reason |
| :--- | :--- | :--- |
| Sign In / Sign Out | `Sign In` / `Sign Out` | Universal clarity; avoid unnatural verb attachments |
| Back | `Back` | Single-action navigation control |
| Save / Cancel | `Save` / `Cancel` | Standard form action |
| Submit / Continue | `Submit` / `Continue` | Universal workflow action |
| Add / Delete / Edit | `Add` / `Delete` / `Edit` | Standard CRUD button verbs |
| Search / Filter | `Search` / `Filter` | Standard data table controls |
| Close / Dismiss | `Close` | Modal / Alert dismiss control |

---

## 4. Photography & Business Terminology Policy

The following terms **MUST ALWAYS** remain in standard English in Tanglish strings:
- **Studio & Roles:** `Studio`, `Crew`, `Lead Photographer`, `Cinematographer`, `Editor`, `Drone Operator`
- **Workflow & Media:** `RAW Photos`, `Ingest`, `Selection`, `Color Grading`, `Teaser`, `Full Film`, `Album Design`, `Print Lab`, `Deliverables`
- **Commercial & OMS:** `Order`, `Milestone`, `Advance`, `Shoot Day Payment`, `Balance Due`, `Invoice`, `GST`, `Payroll`, `Claims`
- **Integrations:** `Google Drive`, `Google Calendar`, `WhatsApp Notifications`
