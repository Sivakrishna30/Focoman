# Task 04: UI Control Language Standardization

## Objective
Enforce the Single-Word Button and Universal Control Rule across all language options for buttons, action triggers, and table navigation.

## Scope
- `apps/web/src/components/BackButton.tsx`
- `apps/web/src/components/Navbar.tsx`
- `apps/web/src/components/DashboardTopNav.tsx`
- `apps/web/src/components/DashboardSidebar.tsx`
- Modal dialog action buttons

## Rules
- Simple action triggers (Sign In, Sign Out, Back, Save, Cancel, Add, Edit, Delete, Submit, Close, Filter, Search) remain clear, single English verbs across all language modes.
- Descriptive tooltips or secondary guidance can adapt to the user's selected language.
