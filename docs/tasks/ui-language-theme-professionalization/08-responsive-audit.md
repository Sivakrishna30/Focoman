# Task 08: Responsive Layout Audit (320px – 414px & Desktop)

## Objective
Audit and verify responsive viewport layouts across 320px (iPhone SE 1st gen), 360px (Galaxy S series), 375px (iPhone SE 2/3), 390px (iPhone 13/14), 414px (iPhone Plus/Max), and Desktop.

## Acceptance Criteria
- [ ] No horizontal layout scrolling or text overflow.
- [ ] Touch targets are at least 44px x 44px where applicable.
- [ ] Modal dialogs and action sheets adapt gracefully to screen width.
