# FOCOMAN Brand Assets

This folder stores source brand images for use in future UI work.

## Files

- `focoman-logo-mark.png`
- `focoman-logo.png`

## Usage

When the frontend project is created, copy or reference these assets from the UI asset folder, for example:

```text
focoman-frontend/public/brand/
```

Keep original files here as the canonical project-level brand assets.
